# Keloy Studio

Одностраничный лендинг веб-студии Keloy Studio — тёмная премиум-тема, анимации на CSS и Intersection Observer, без внешних JS-библиотек.

## Стек

- Чистый HTML + CSS + JS в одном файле — [`index.html`](index.html)
- Шрифты: Bricolage Grotesque, Manrope, JetBrains Mono (Google Fonts)

## Запуск

Открыть [`index.html`](index.html) в браузере — сборка и зависимости не требуются.

## Структура контента

Список услуг и цен задан массивом `services` в `<script>` в конце `index.html` — редактируется прямо там, без изменения разметки.
